# Minimal example

Preview what `pnpm gen:utils-book` produces: sample array utils and a pre-generated utils-book.

**Human quick start:** [package README](../../README.md) · [README.zh-CN](../../README.zh-CN.md)

Browse [`docs/agent-catalog/utils-book/`](docs/agent-catalog/utils-book/) in this folder.

Regenerate locally (from `examples/minimal/`):

```bash
node ../../bin/cli.mjs gen
```

In your own project after `agent-utils-reuse init`, the same layout appears under your configured paths. Agent rules live in `docs/agent-catalog/placement-decision.md`.
